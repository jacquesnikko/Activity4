# Applied Mathematics Activity 3 — Week 3 Turret Defense

A small Unity 2D level demonstrating manually implemented game mathematics. The player begins on the left side of the arena and must reach the green goal on the right while avoiding three turret types.

## Controls

- Move with **WASD** or the **arrow keys**.
- Touching any projectile reloads the scene immediately.
- Reaching the green goal disables every turret and displays the Win UI.

## Turrets

- **Flame Turret:** rotates toward the player, performs a manual cone test, and continuously emits flame particles while the player remains inside the cone.
- **Sniper Turret:** uses a narrow manually calculated sight line and fires one fast shot when the player enters it. The sniper rearms only after the player leaves the sight line.
- **Shotgun Turret:** rotates toward the player, performs a manual cone test, and fires seven pellets across a calculated angular spread.

Each danger zone is drawn with a `LineRenderer`. The lines are visualization only and do not perform detection.

## Manual-math requirement

The project does not use colliders, triggers, Rigidbody physics, Physics2D queries, or raycasts. Gameplay uses code in `Assets/Scripts/ManualMath.cs` for:

- vector normalization and dot products;
- `atan2` direction angles and wrapped angle differences;
- cone and line-of-sight detection;
- circle-versus-rectangle player movement;
- swept segment-versus-circle projectile hits; and
- swept projectile-versus-wall checks.

Unity handles rendering, keyboard input, transforms, UI, timing, and scene loading only.

## Setup

1. Open this directory as a Unity project using Unity **6000.3.14f1** or a compatible Unity 6 version.
2. Open `Assets/Scenes/Week3TurretDefense.unity`.
3. Press Play.

The level itself is generated by `Week3LevelBootstrap.cs`, so gameplay objects do not require manual Inspector configuration.

If the scene file needs to be recreated, run **Applied Mathematics > Build Week 3 Scene** from Unity's menu.
